Prompt API Not Enabled

To use this free on-device AI, please enable it in Chrome:

  1. Go to chrome://flags/#prompt-api-for-gemini-nano and set to Enabled
  2. Go to chrome://flags/#optimization-guide-on-device-model and set to Enabled BypassPrefRequirement
  3. Relaunch Chrome
  4. Go to chrome://components, find Optimization Guide On Device Model and click Check for update.
